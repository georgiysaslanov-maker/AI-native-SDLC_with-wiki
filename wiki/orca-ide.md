# Orca (IDE-оркестратор агентов)

> Десктоп-приложение уровнем выше агента: запускает любые терминальные агенты (OpenCode, Pi, Codex, Claude Code) в изолированных worktree, с встроенным браузером, интеграцией с Jira и мобильным доступом.

## Содержание

По докладу А. Захватова (название в транскрипте — «ORCA / Orca / Org», распознавание неточное):
- Любой терминальный агент запускается в Orca и получает свой **worktree** — изолированную локальную копию репозитория, а не просто переключение ветки.
- Мультиагентность, поддержка подписок разных инструментов; интерфейс как у IDE: проекты и worktree, дерево файлов, git diff, история всех сессий агентов.
- Интеграция с Jira по токену: видеть свои задачи, стартовать worktree по задаче.
- Автоматизации по крону: еженедельный аудит задач команды (статусы, потерянные комментарии, приёмки), аудит собственной работы с агентами за неделю, анализ изменений в репозитории QA-агента.
- Мобильное приложение подключается к живой сессии.
- Встроенный браузер: выделить участок страницы или аннотацию и отправить в сессию агента (полезно для фронтенда).
- Сравнение вариантов: запустить разных агентов на одной задаче в изолированных worktree и сравнить результаты (например, два варианта описания skill).
- Бесплатна, обновляется почти ежедневно; использовать необязательно — подойдёт любой терминал.
- Аналоги из доклада: терминальные оркестраторы, облачный Devin, расширяемый плагинами инструмент (в транскрипте «BB»).
