# Человеческие гейты (gates)

> Точки, где продолжение конвейера требует утверждения человеком; агент действует до гейта, но не за него.

## Содержание

**Определение (глоссарий методики):** gate — точка, где продолжение требует утверждения человеком. Технически гейт = запрос ревью MR + защита веток; кого спрашивают, решает CODEOWNERS по пути файла.

### Гейты конвейера
| Гейт | Что утверждается | Кто |
|---|---|---|
| Утверждение `intent.md` | вход в Design | владелец по классу изменения: PO (бизнес) или инженер (техника) |
| **Гейт 1 — бизнес-приёмка** | `proposal` + `specs` | продукт (PO / аналитик); обязателен при изменении внешне наблюдаемого поведения / публичного контракта |
| **Гейт 2 — техническая приёмка** | `design` + `tasks` | инженер; вход в Build |
| Чекпоинт плана (Build) | дополненный `tasks.md` | инженер; **не гейт** (нет merge), со зрелостью отключается для рутины |
| Merge | код в PR | живой владелец кода (CODEOWNERS + защита веток) |
| Авторизация прод-релиза | прод-деплой | назначенный владелец (тимлид / владелец кода); gate-hook типа «спросить» |

### Правила
- Утверждает человек, не агент; агент, написавший код, не имеет способа его утвердить (разделение полномочий).
- Автономия растёт, но гейты остаются человеческими; меняется только триггер запуска стадий (ручной → событийный).
- Автономия по окружениям: dev — агент деплоит свободно; staging — автономно за автопроверкой; prod — готовит агент, авторизует человек.
- Риск «узкого горлышка»: если все изменения идут через Гейт 1, они упрутся в ~20 продуктологов — поэтому класс изменения решает, нужен ли Гейт 1.

### На митапе
Ожидается, что «на каждом из гейтов будет стоять человек, который контролирует результат каждого агента». Встречный вопрос из зала: чтобы контролировать, человек должен точно знать, что должно получиться — это не генерация картинки, где результат виден интуитивно. В pet-проекте Румянцева роль гейта выполнял он сам: агент показывал результат по каждому критерию приёмки, и только после подтверждения начиналась следующая веха.
