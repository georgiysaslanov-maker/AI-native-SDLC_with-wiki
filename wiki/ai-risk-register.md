# Реестр рисков AI-SDLC

> Сводка 21 риска методики (R-01…R-21) с вероятностью, влиянием и мерами снижения; критичные — утечка ПДн и блокировка Enterprise-аккаунта.

## Содержание

| ID | Риск | Вер. / влияние | Ключевые меры |
|---|---|---|---|
| R-01 | Утечка ПДн и чувствительных данных во внешний API | сред / критич | запрет реальных данных, синтетика, скан diff, маскирование логов |
| R-02 | Код, US, proto покидают периметр при каждом вызове | выс / выс | классификация репозиториев, Enterprise, ограничение трафика |
| R-03 | Галлюцинации | выс / выс | SDD с источником, самопроверка, evals, ревью, утверждение человеком |
| R-04 | Prompt injection | сред / выс | недоверенный контент — данные; deny-правила; sandbox |
| R-05 | Деградация качества при росте автономии | сред / выс | автономия по метрикам, gate на изменения конфигурации через evals |
| R-06 | Снижение ответственности инженеров | сред / сред | человек отвечает за суждение, атрибуция |
| R-07 | Неконтролируемая стоимость | выс / сред | лимиты, мониторинг токенов |
| R-08 | Зависимость от вендора | сред / сред | слой абстракции |
| R-09 | Слабая воспроизводимость | сред / сред | версионирование конфигурации, evals |
| R-10 | «Спека ради спеки» | сред / низ | объём спеки пропорционален изменению |
| R-11 | Теневое использование AI (15 команд) | выс / сред | политика, обучение |
| R-12 | Автономия включена слишком рано | сред / выс | обязательная зрелость gate |
| R-13 | Юрисдикция хранения | низ / выс | тайна связи и ПДн не попадают в контекст и логи |
| R-14 | Блокировка Enterprise-аккаунта (след из РФ) | сред / критич | вендор-нейтральность; принятый риск |
| R-15 | Легаси-путь держится на связке reverse-spec-скилл + инженер + продукт | сред / выс | go/no-go Фазы 0, запасной план |
| R-16 | Недо-ресурсность Фазы 0 (part-time) | сред / выс | защищённое время, выделенный Tech-lead |
| R-17 | Горлышко продукта (~20 чел.) | выс / сред | greenfield-first, продуктовый пресет |
| R-18 | Отставание продуктового и сервисного контекста | сред / выс | тонкий старт, каркас от платформы, «ошибся дважды → контекст» |
| R-19 | Межсервисная фича буксует | сред / сред | contract-first, оркестратор-интегратор; Tiny Teams стратегически |
| R-20 | Трансформация ролей ~150 человек неравномерна | сред / выс | волны/когорты, метрика адопшна по командам, «пол» для всех |
| R-21 | Давление сроков: годовой план до данных | сред / выс | data-gated plan: твёрдо только Фаза 0, дальше сценарии |

Риски, звучавшие на митапе: правдоподобный, но неверный результат и размывание ответственности (≈ R-03, R-06); блокировки аккаунтов провайдерами (≈ R-14); деградация навыков разработчиков (в реестре отдельно нет, в методике — правило для джунов).
