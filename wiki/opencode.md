# OpenCode

> Открытый терминальный кодинг-агент, позволяющий подключать разных провайдеров LLM; выбран методикой как харнесс L2 на старте и широко используется практиками.

## Содержание

- **Методика:** харнесс L2 «сегодня» (Claude Code — потенциально позже); слой L1/L2/L3 Фазы 0 строится на opencode; у OpenSpec есть плагин под opencode. Продукт работает через «продуктовый режим» — пресет/скилл в OpenCode, скрывающий git и терминал (Решение: продукт пишет в репозиторий через обёртку, например OpenCode CLI).
- **Митап:**
  - «Кодинг-агент-инструмент, который является провайдером для работы с другими LLM»: есть бесплатные модели в рамках OpenCode с ограничениями, можно подключать платные подписки и разных провайдеров, теоретически — локальные модели.
  - План: развернуть OpenCode внутри компании — чувствительные данные во внутреннюю LLM, нечувствительные во внешнюю, управление через OpenCode.
  - Используют: И. Румянцев (GLM в pet-проекте), Н. Токарев (DeepSeek для анализа нагрузки); упоминается Pi как «родственник OpenCode».
  - PO в межсервисном примере методики описывает интент «через OpenCode-пресет».
