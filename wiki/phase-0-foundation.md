# Фаза 0 (фундамент) и выбор пути трансформации

> Обязательная стартовая фаза, одинаковая для любого пути: организационный доступ, слой агентов, контроли, шаблоны, baseline и сквозной прогон на двух образцах; после неё на данных выбирается путь (greenfield-first / transform-first / два трека).

## Содержание

### Что строится
| Что | Выход |
|---|---|
| Организационный доступ + реестр разрешённых моделей | ключи под управлением платформы (запускается сразу — календарно-зависимо) |
| Слой L1/L2/L3 на opencode; OpenSpec | агент запускается, артефакты ведутся |
| Reverse-spec скиллы; коннекторы к коду, TestIT, Confluence | агент читает три источника легаси |
| Политика AI, правила по данным, скан ПДн/секретов, защита веток | `main` защищён, скан блокирует |
| Каркас независимого приёмочного гейта | человеческая верификация защищена |
| Шаблоны intent/spec/plan/review, первые общие skills | команды берут готовое |
| Продуктовый пресет для OpenCode | продукт работает через CLI, не через git |
| Baseline процесса (lead time, deploy frequency, время ревью, доля дефектов) | снимают DevOps + QA, вне build-команды платформы |
| Назначен состав платформы | program-owner, Tech-lead, локальные эксперты |

- **Сквозной прогон на двух образцах:** greenfield-изменение полным циклом + reverse-spec на 2–3 живых легаси-сервисах. Замер: число обращений и стоимость, время до принятой спеки, объём человеко-валидации; дельта — вход в выбор пути и первая прикидка токен-экономики.
- **Reverse-spec-образец = go/no-go** легаси-пути: смог ли продукт вынести вердикты по бизнес-вопросам.
- **Критерий готовности:** политика разработана; baseline снят; сквозной прогон на двух образцах пройден и замерен.
- Горизонт — TBD, оценка объёма — снизу вверх командой.

### После Фазы 0
| Вариант | Суть | Что проверяет |
|---|---|---|
| Greenfield-first | 1–2 новых сервиса полным циклом | работает ли конвейер вглубь |
| Transform-first | baseline легаси + наполнение контекста | масштабируется ли reverse-spec вширь |
| Два трека | оба одновременно | глубину и ширину ценой нагрузки на продукт |

**Рекомендация — greenfield-first:** не конкурирует за продукт (~20 человек против ~130 инженеров), даёт ранние данные по стоимости и lead time. Легаси идёт фоном небольшой микрокомандой — только после go/no-go и с некритичных сервисов. Если стоимость окажется выше ожидаемой, пересматривается дизайн (объём внешнего API, класс задач, автономия), а не факт продолжения.

**Data-gated plan (R-21):** твёрдо коммитится только Фаза 0; остальной год — сценарии с датами решений, цифры и ROI диапазонами.
