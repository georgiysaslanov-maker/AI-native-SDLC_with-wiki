# MWS GPT Model Hub

> Сервис MWS Cloud (МТС Web Services): API к открытым LLM, развёрнутым в российском облаке группы МТС. Главный кандидат на организационный доступ к модели для Фазы 0.

## Содержание

- **Запуск:** 24 марта 2026. Доступ по API внутри MWS Cloud Platform, совместим с OpenAI — подключается к [[opencode]] через шлюз без доработок.
- **Модели:** DeepSeek, Gemma, Qwen, Zhipu (GLM), Moonshot (Kimi), BAAI и др. С 4 сентября 2026 — GLM-5.3 (MWS заявляет, что первой в России). Анонсированы TTS/ASR-модели и реранкеры.
- **Данные:** модель локализована в РФ, запросы и данные пользователей не покидают страну. Это снимает зависимость от VPN и риск блокировки за след из РФ (R-14).
- **Цена GLM-5.3:** «на уровне GLM-5.2»; в документации MWS есть два разных значения (см. «Противоречия»).
- **Связь с организацией:** MWS — часть группы МТС, как и [[mts-exolve]], — договор внутри группы.
- **Упоминание на митапе:** в докладе о нагрузочном тестировании говорилось, что провайдера можно настроить «к нашим моделям … от МТС — Qwen 3.5 с контекстным окном 256 тыс. токенов» ([[case-ai-load-test-analysis]], [[organizational-model-access]]). Скорее всего, это MWS GPT, но транскрипт автоматический — уточнить.
- **Что проверить при заключении договора:**
  - что данные не используются для обучения;
  - срок хранения логов;
  - лимиты запросов и SLA;
  - есть ли prompt caching и сколько он стоит;
  - актуальный список и версии моделей, скорость появления новых.

## Противоречия

- **Тариф GLM-5.3.** Тарифная строка: 70,76 ₽ за 1M входных и 283,04 ₽ за 1M выходных токенов (с НДС 22%). Таблица в той же документации: 178,12 ₽ / 746,64 ₽ с неясной единицей. Источник — mws.ru/docs, через [[research-llm-alternatives-2026-10]]. Комментарий: возможна ошибка в документации или разные режимы — уточнить у MWS.
- **Число моделей:** 10 LLM на запуске (пресс-релиз) против «более 90 LLM» (другой материал MWS). Комментарий: вероятно, разные даты или способ подсчёта.
